# Название проекта: WPFBankID - Информационная система банковского обслуживания

Данный проект представляет собой информационную систему банковского обслуживания на платформе WPF. Приложение использует модель Entity Framework для работы с базой данных MS SQL Server и обеспечивает функции авторизации, регистрации пользователей и отправки банковских заявок.

## Установка

1. Клонируйте репозиторий: git clone https://github.com/nika-persik/Muravina_Veronika_Alexandrovna_LR1

2. Откройте решение:
   Запустите среду разработки Microsoft Visual Studio и откройте файл решения WPFBankID.sln.

3. Восстановите зависимости:
   Выполните сборку проекта. Среда Visual Studio автоматически загрузит необходимый пакет EntityFramework.

4. Подключите базу данных:
   Убедитесь, что на локальном сервере развернута СУБД MS SQL Server с базой данных BankID, а строка подключения в файле App.config указывает на ваш сервер.

## Использование

Приложение предоставляет пользователю следующие возможности:
* Авторизация в системе по логину и паролю.
* Регистрация нового аккаунта с заполнением персональных данных и проверкой капчи.
* Просмотр баланса, валюты, процентной ставки и дат работы активных счетов и вкладов в личном кабинете.
* Подача заявок на изменение персональных данных, а также на открытие или закрытие банковских продуктов.
* Генерация и сохранение официальной выписки по выбранному счету в текстовый файл формата .txt.

## Структура проекта

В результате рефакторинга исходный код проекта был разделен на следующие функциональные каталоги:
* Core/ — содержит класс DataEncryption.cs, отвечающий за логику шифрования данных пользователей.
* Infrastructure/ — содержит каталог Entities/, в котором расположены автогенерируемые модели таблиц и контекст подключения к базе данных.
* Views/ — содержит файлы графического интерфейса (окна и страницы приложения):
  * MainWindow.xaml — главное окно приложения.
  * AuthorizationPage.xaml — страница входа.
  * RegistrationPage.xaml — страница регистрации новых клиентов.
  * PersonalAccountPage.xaml — страница личного кабинета.
  * ChangeDataPage.xaml — форма изменения персональных данных.
  * RequestHistoryPage.xaml — история поданных заявок.

## Данные

Для хранения информации приложение использует реляционную базу данных под управлением MS SQL Server. В целях безопасности персональные данные клиентов (фамилия, имя, отчество, серия и номер паспорта, дата рождения) проходят процедуру шифрования перед сохранением в базу данных. Обратная расшифровка выполняется динамически только после успешной авторизации пользователя.
